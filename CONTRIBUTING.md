# Contributing

Thanks for your interest in improving PalgharAI-RAG.

## Before opening a change

1. Explain the issue or improvement and its impact on document retrieval, OCR, multilingual support, or usability.
2. Keep API keys, private PDFs, extracted text, ChromaDB directories, and backup archives out of commits.
3. Do not add third-party source documents unless redistribution is permitted.
4. Update the README when setup steps, dependencies, model defaults, or limitations change.
5. Test notebook cells in order in a fresh Colab runtime when practical.

## Suggested areas

- Marathi/Hindi/English OCR quality and evaluation
- Retrieval relevance and source-page correctness
- Safer deployment and access control
- Knowledge-base backup/restore reliability
- Clearer error handling and user guidance

## Reporting issues

Include the relevant notebook step, runtime type, sanitized error message, and a minimal reproduction. Never include API keys or confidential document content.
